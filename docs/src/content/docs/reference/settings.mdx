---
title: Settings reference
description: Every option in Settings and Customize, with its values and default.
---

Every option, with the name you see in the app, its values and what it starts with. The key in `settings.json` (see [File locations](../files/)) is shown under each name. Amounts are sliders; held, they rest a moment on the levels listed as "rests on".

**Put everything back as it came** (Settings › General) puts all of these back to their defaults and turns **Start with Windows** off. Pinned apps, the Media tab, background folders and learned words stay.

## Appearance

| Option | Values | Default |
|---|---|---|
| **Main color**<br />`accent` | Blue, Violet, Green, Amber, Pink, Ivory | Blue |
| **High contrast**<br />`high_contrast` | On / off | Follows Windows' high contrast |
| **Text size**<br />`text_size` | 100 to 150 %, in steps of 5; rests on 110, 120 and 135 % | 100 % |
| **Thicker selection frame**<br />`thick_focus` | On / off | Off |
| **Background**<br />`wallpaper` | A built-in animation, a Wallpaper Engine video, a video or picture from your folders, or none | Diagonal wave |
| **Show song lyrics**<br />`music_lyrics` | On / off | Off |
| **Game pictures**<br />`game_art` | On / off | On |
| **Home layout**<br />`library_view` | Wide, Covers, Grid, List | Wide |

## Customize only

| Option | Values | Default |
|---|---|---|
| **Darken the background**<br />`wall_dim` | 0 to 100 %, in steps of 5; rests on 25, 50 and 75 % | 0 (Off) |
| **Game order**<br />`game_order` | Recent, A–Z (open games always first) | Recent |

## Buttons

| Option | Values | Default |
|---|---|---|
| **Layout**<br />`hand` | Both hands, Left hand, Right hand | Both hands |
| **Customize buttons**<br />`button_map` | For A, B, X, Y, LB, RB, LT, RT, L3, R3 and each d-pad direction: what any of those does, scroll up, scroll down or nothing | Each button does its own |
| **Controller color**<br />`pad_theme` | Graphite, Carbon, Dots, Navy, Petrol, Wine, Forest, Olive, Plum, Slate, Bone, Sand, or Random | Graphite |
| **Accept with B**<br />`swap_ab` | On / off | Off |
| **Pointer on the right stick**<br />`swap_sticks` | On / off | Off |
| **Hold time**<br />`hold_time` | 0.3 to 1.2 s, in steps of 0.05 s; rests on 0.4, 0.6 and 0.9 s | 0.6 s |

## Pointer

| Option | Values | Default |
|---|---|---|
| **Pointer speed**<br />`cursor_speed` | 40 to 200 %, in steps of 5; rests on 70, 100 and 140 % | 100 % |
| **Aim assist**<br />`slowdown` | 0 (Off) to 80 %, in steps of 5; rests on 35, 55 and 75 % | 55 % |
| **Ignore small movements**<br />`deadzone` | 4 to 25 % of the stick's travel; rests on 8, 12 and 18 % | 12 % |
| **Scroll speed**<br />`scroll_speed` | 30 to 250 %, in steps of 10; rests on 50, 100 and 160 % | 100 % |
| **Reverse scrolling**<br />`invert_scroll` | On / off | Off |

## TV mode

| Option | Values | Default |
|---|---|---|
| **TV mode** | On / off | Off |
| **TV screen**<br />`tv_display` | One of the connected screens | None chosen |

| Option | Values | Default |

| **Covers and lyrics from the internet**<br />`music_online` | On / off | On |
| **Vibrate when the mode changes**<br />`rumble` | On / off | On |
| **Menu layout**<br />`settings_view` | List, Tiles | List |
