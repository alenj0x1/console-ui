## La bienvenida

La primera vez que se abre Console UI empieza una breve práctica. Cada paso se termina haciéndolo con el control, en una ventana normal que el puntero maneja como cualquier otra:

| Paso | Qué haces |
|---|---|
| **Hola** | Mueve el puntero con la palanca izquierda y presiona <Btn b="A" /> sobre cada uno de tres círculos. |
| **Cómo se siente el puntero** | Elige la velocidad del puntero (**Lenta**, **Normal**, **Rápida**) y cuánto movimiento de la palanca ignorar (**Poco**, **Normal**, **Mucho**). Cada elección se aplica al instante, así que puedes probarla. |
| **El teclado** | Presiona <Btn b="Y" /> para abrir el teclado, escribe *hola*, presiona <Btn b="RT" /> para enviarlo y <Btn b="B" /> para cerrar el teclado. |
| **Inicio** | Mantén <Btn b="Menu" /> para abrir Inicio y luego <Btn b="B" /> para volver. |
| **Centro de control** | Presiona <Btn b="View" /> para abrir el centro de control y luego <Btn b="B" /> para volver. |
| **Listo** | Unas cosas más que vale la pena saber: <Btn b="LT" /> con la cruceta salta entre botones, mantener <Btn b="View" /> abre el menú rápido, mantener <Btn b="View+Menu" /> abre el centro de control en un juego, y todo se cambia en Ajustes. |

**Saltar** la termina en cualquier momento. Para repetirla después, abre **Ajustes › General › Practicar con el control** en la pantalla de inicio.

## Cómo arranca la app

- Al abrir Console UI aparece [Inicio](../../guide/home/). Si la abres otra vez mientras funciona, vuelve ese mismo Inicio en lugar de una segunda copia.
- Con **Iniciar con Windows** activado (Ajustes › General), arranca en silencio en la bandeja cuando inicias sesión.
- La app vive en el área de notificaciones (la bandeja). Un clic en su ícono abre Inicio; su menú tiene **Abrir Inicio**, **Abrir teclado**, **Dejar el control a los juegos** (después dice **Volver a usar el control en Windows**, para recuperarlo) y **Salir**.

## Avisos

Aparecen avisos breves cuando el control se conecta (con su nivel de batería), se desconecta o se queda con poca batería, cuando un juego toma el control y cuando una [ventana de administrador](../../troubleshooting/#el-control-no-hace-nada-sobre-una-ventana) lo bloquea.

Sigue con los [controles](../../guide/controls/).
